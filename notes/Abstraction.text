### Abstraction 

hiding implementation and showing only essentail feature 
"Abstraction is the process of hiding the implementation details and showing only the essential features to the user."

### Analogy: When you drive a car, you just use the steering wheel, accelerator, and brake (essential features). You don't need to know how the engine, fuel injection, or transmission works internally (hidden complexity).


### Why We Need It
Simplicity — user only deals with what's necessary
Reduces complexity — hides messy implementation details
Security — internal logic/data can't be tampered with
Easier maintenance — you can change internal implementation without affecting how others use it
